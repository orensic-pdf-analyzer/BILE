એડમિન: બિલ (PDF) અપલોડ

અહીં ફક્ત PDF પસંદ કરવાની છે. બ્રાઉઝર દરેક PDF ને તમારા જ કમ્પ્યુટરમાં એન્ક્રિપ્ટ કરે છે; મૂળ PDF ક્યાંય મોકલાતી નથી.

આ પેજ પર પાસવર્ડ નથી. સુરક્ષા આ છે: GitHub repo માં ફક્ત જેને લખવાની પરવાનગી છે તે જ બિલ મૂકી શકે. મૂળ PDF કે CSV ક્યારેય GitHub પર મૂકવી નહીં.

1. PDF પસંદ કરો

2. CSV (વૈકલ્પિક)

જો PDF નું નામ ફક્ત ટેનામેન્ટ નંબર હોય (જેમ કે 12345.pdf) તો CSV મૂકો. પહેલી લીટી: tenement,mobile

3. ક્યાં સાચવવું

GitHub ફોલ્ડર (તમારા કમ્પ્યુટર પર) નો docs/b ફોલ્ડર પસંદ કરો. ફાઇલો સીધી ત્યાં લખાશે.

પસંદ કરેલ: કોઈ નહીં

આ ફોલ્ડરનું નામ b નથી. ખાતરી કરો કે તમે docs/b જ પસંદ કર્યું છે.

આ બ્રાઉઝરમાં ફોલ્ડર સીધું પસંદ થઈ શકતું નથી, એટલે ZIP ફાઇલો બનશે. (Chrome કે Edge માં ફોલ્ડર સીધું ચાલે છે.)

ફોલ્ડર ન પસંદ કરો તો ZIP ફાઇલો બનશે, તેને docs/b માં Extract કરવી.

      પછી શું કરવું

      1. GitHub Desktop ખોલો, ફેરફારો દેખાશે. Commit અને પછી Push કરો.
      2. 1-2 મિનિટમાં વેબસાઇટ પર બિલ ઉપલબ્ધ થઈ જશે.
      3. બિલ હટાવવું હોય તો docs/b માંથી તે ફાઇલ ડિલીટ કરીને Push કરો. બિલ બદલવું હોય તો નવું PDF ફરીથી એન્ક્રિપ્ટ કરો.
